# Tonghe Electric Power

Marketing site for Tonghe Electric Power — custom transmission-line monitoring and underground cable inspection equipment.

Static HTML. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html      # full page
images/         # photos and logo
```

Contact form opens a `mailto:` draft. Update the destination email in `index.html` before going live.

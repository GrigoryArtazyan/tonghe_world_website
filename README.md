# Tonghe Electric Power

Marketing site for Tonghe Electric Power — custom transmission-line monitoring and underground cable inspection equipment.

**Visit:** https://tonghe.world/

![Tonghe Electric Power](images/tonghe-hero.png)

Static HTML. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html      # full page
images/         # photos and logo
```

The contact form sends to `info@tonghe.world` (no mail app). The first live submission sends a one-time confirmation to that inbox — click it so messages start arriving.
